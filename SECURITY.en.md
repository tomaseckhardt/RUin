# Security Policy

[Čeština](SECURITY.md) · **English**

## Supported Versions

The project currently actively maintains only the `main` development branch.

| Version        | Supported          |
| -------------- | ------------------ |
| main           | :white_check_mark: |
| older branches | :x:                |

## Reporting a Vulnerability

Please don't report security issues publicly through GitHub Issues.

Use a private channel instead:

1. Create a **private security advisory** in the repository (the Security tab on GitHub), if it's available.
2. If advisories aren't available, contact the maintainers through a private channel agreed on in advance, and send:
   - a description of the issue,
   - its impact,
   - steps to reproduce or a PoC,
   - a suggested mitigation (if you have one).

How the app handles identity and permissions (and what it deliberately doesn't handle) is described in [SECURITY_MODEL.en.md](SECURITY_MODEL.en.md).

## What to Expect

- Confirmation that we received your report, usually within 72 hours.
- Ongoing updates on the fix, once the issue has been reproduced.
- An effort to release a fix within a reasonable time, depending on severity.
- A summary of the impact may be published once the fix is deployed.

Thank you for reporting responsibly.
