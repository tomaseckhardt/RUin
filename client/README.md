# RUin Client

Frontend aplikace pro projekt RUin (React + Vite).

## Spuštění

Z kořene repozitáře:

```bash
npm install
npm run dev
```

Nebo přímo v client složce:

```bash
npm install
npm run dev
```

## Důležité pro contributory

- nepushovat přímo do `main`
- vždy pracovat ve vlastní branch
- změny posílat přes Pull Request do `main`

Příklad:

```bash
git checkout -b feat/kratky-popis-zmeny
git push -u origin feat/kratky-popis-zmeny
```

Podrobnější pravidla jsou v `../CONTRIBUTING.md`.
